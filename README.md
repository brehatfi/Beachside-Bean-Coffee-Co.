# Beachside Bean Coffee Co.

Beachside Bean Coffee Co. is a fictional small business website created as the final project for CMPA-3301. This repository presents a complete project package that combines project planning, documentation, reflection, and a two-page website prototype within a single professional GitHub repository.

Rather than treating the website as only a coding assignment, this project approaches the work through the mindset of the unofficial project manager. The result is a repository that demonstrates how a small digital project can be scoped, planned, executed, and evaluated from beginning to end.

## Project Purpose
The purpose of this project is to design and develop a simple, professional two-page website for a fictional coffee shop while also applying the project management principles from *Project Management for the Unofficial Project Manager*. This project reflects course concepts related to scope definition, planning, accountability, risk awareness, and retrospective learning.

The website serves as the technical artifact of the project, while the supporting documentation demonstrates the planning and management process behind it.

## Project Theme
Beachside Bean Coffee Co. is a fictional coastal coffee shop designed to represent a small business seeking a clean, inviting online presence. The website introduces the business, communicates its identity, and provides a basic but professional customer-facing experience.

## Repository Contents

### Root Directory
- `index.html` — homepage for the fictional business
- `about.html` — second page describing the company story, mission, and values
- `style.css` — shared stylesheet for both pages
- `README.md` — repository homepage and project overview

### Documentation Folder
The `docs/` folder contains the project management documentation:

- [`scope.md`](docs/scope.md) — Project Scope Statement
- [`plan.md`](docs/plan.md) — project plan with TAME risk analysis and work breakdown structure
- [`retrospective.md`](docs/retrospective.md) — project reflection on outcomes, challenges, and future improvement

## Project Features
