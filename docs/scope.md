# Project Scope Statement

## Project Title
**Beachside Bean Coffee Co. Website Project**

## Project Purpose / Justification
The purpose of this project is to design and develop a simple, professional two-page website for a fictional small business called **Beachside Bean Coffee Co.** The website will provide basic business information, introduce the brand, and create an online presence for potential customers. This project supports the final course objective of acting as an unofficial project manager by combining planning, documentation, and execution into one complete digital project.

This website project is intentionally limited in technical complexity so that the focus can remain on quality, organization, and the application of project management principles. In addition to meeting course requirements, the final repository will serve as a portfolio piece that demonstrates project planning, documentation, and introductory web development skills.

## Project Objectives
The objectives of this project are to:

- Create a public GitHub repository that contains all required project files and documentation.
- Develop a two-page website for **Beachside Bean Coffee Co.** using HTML and CSS.
- Build a homepage (`index.html`) that introduces the business, highlights products or services, and provides clear navigation.
- Build a second page (`about.html`) that explains the story, mission, and values of the fictional business.
- Apply a consistent visual style across both pages using one external stylesheet (`style.css`).
- Create planning documentation in Markdown format, including scope, plan, and retrospective files.
- Produce a professional `README.md` file that explains the project and links to the live website and documentation.

## Product Scope Description
The final product will be a basic informational website for a fictional coffee shop. The website will consist of two linked web pages and one shared stylesheet. The site will be designed for desktop and basic mobile readability, with a clean layout, readable text, and consistent branding. It will include business information, descriptions of products or services, and an about page that communicates the identity of the fictional company.

In addition to the website itself, the project will include project management documentation housed in the same GitHub repository. These documents will explain the project scope, task planning, risk considerations, and lessons learned during the project process.

## High-Level Requirements
The project must meet the following requirements:

- The project must be housed in one public GitHub repository.
- The repository must include a professional `README.md` file.
- The repository must include a `docs/` folder containing:
  - `scope.md`
  - `plan.md`
  - `retrospective.md`
- The root directory must include:
  - `index.html`
  - `about.html`
  - `style.css`
- The website must include working navigation between the two pages.
- The website must use valid basic HTML structure and an external CSS file.
- The design must remain simple, organized, and appropriate for a fictional small business.
- The content must be original and appropriate for an academic project.
- The final project must reflect project management concepts from *Project Management for the Unofficial Project Manager*.

## Deliverables
The deliverables for this project are:

1. **Public GitHub Repository**
2. **README.md**
   - Project overview
   - Purpose of the website
   - Link to live website
   - Link or reference to the documentation folder
3. **docs/scope.md**
   - Detailed Project Scope Statement
4. **docs/plan.md**
   - Project plan, including risk analysis and work breakdown structure
5. **docs/retrospective.md**
   - Reflection on project outcomes and process
6. **index.html**
   - Homepage for **Beachside Bean Coffee Co.**
7. **about.html**
   - About page for **Beachside Bean Coffee Co.**
8. **style.css**
   - Shared external stylesheet for both pages

## Boundaries / Out of Scope
To keep the project realistic and manageable, the following items are out of scope:

- E-commerce functionality
- Online ordering or payment systems
- Customer login or account creation
- Contact form with backend processing
- Database integration
- JavaScript interactivity beyond basic HTML/CSS structure
- More than two website pages
- Advanced responsive design for multiple breakpoints
- Search engine optimization beyond basic page titles and headings
- Real business deployment for a live company

## Constraints
This project is subject to the following constraints:

- The website must be completed within the timeframe of the course.
- The project must remain simple enough for one student to complete independently.
- Only basic web development tools and skills will be used.
- The website must consist of only two pages and one external stylesheet.
- The project must align with assignment instructions and course expectations.
- The work must be organized clearly within a single GitHub repository.

## Assumptions
This project assumes that:

- The user viewing the website wants basic information about the fictional business.
- GitHub will be available for hosting the repository.
- The student has access to a code editor and internet connection.
- Basic HTML and CSS will be sufficient to meet the assignment requirements.
- The fictional business content can be created without the need for outside client approval.
- The scope can remain limited to informational content rather than advanced web features.

## Stakeholders
The stakeholders for this project include:

- **Student Project Manager / Developer:** Responsible for planning, building, organizing, and submitting the project.
- **Instructor:** Reviews the project for completion, quality, and alignment with course outcomes.
- **Class Peers:** May provide feedback during discussion or peer review activities.
- **Intended Website Audience:** Potential customers of the fictional coffee shop who want to learn about the business and its offerings.

## Success Criteria
This project will be considered successful if:

- All required files are included and properly organized in the GitHub repository.
- The website contains two complete and linked HTML pages.
- The CSS file applies a consistent and professional style to both pages.
- The `README.md` clearly explains the project and repository contents.
- The documentation files are complete, thoughtful, and professionally written.
- The scope of the project stays realistic and manageable.
- The project demonstrates both project management planning and basic website development skills.

## Acceptance Criteria
The project will be accepted when:

- The GitHub repository is public and accessible.
- All required website and documentation files are present.
- The website functions correctly with no broken page links.
- The site content matches the approved project scope.
- The final submission meets the instructions provided in the course assignment.

## Approval
By completing and submitting this scope statement, the project manager agrees to use this approved scope as the guiding document for the remainder of the project, unless revisions are required by instructor feedback or project review.
